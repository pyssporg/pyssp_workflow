# Authoring environment. The authoring layer shells out to the `pyssp` CLI and
# never imports pyssp_sysml2 or pyssp_standard, so this environment can pin a
# different pyssp_standard revision from the runtime one.
#
#   pip install -r requirements-sysml.txt
#
# The SysML bundle (experimental-pyssp-standard, pyssp-sysml2, pycps-sysml2,
# pyfmi-sysml2) is installed from pyproject.toml base dependencies, so no
# vendored checkouts are required.
