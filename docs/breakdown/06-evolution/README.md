# Evolution

Forward-looking design and decisions. Nothing here is implemented unless its
status says so.

| ID | Title | Status |
| --- | --- | --- |
| ED-001 | [Judgment under a policy](ED-001-judgment-under-policy.md) | Proposed |

Evolution decisions (`ED`) record a direction of travel before code exists.
Once a direction is implemented, the durable rules belong in `02-architecture/`
and the artifact shapes in `03-implementation/schema/`. An ED that is abandoned
stays in place with its status changed, so the reasoning is not lost.
