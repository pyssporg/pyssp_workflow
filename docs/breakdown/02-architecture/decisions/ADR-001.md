# ADR-001: Node-First Topology with an Evidence-First Core

**Status:** Accepted
**Layer:** architecture-decision

---

## Context

The library must support parallel, audited verification campaigns over SSP
models, SysML-derived SSPs, and measured data. The available orchestration
engine is `sequence_extensions`, whose unit of work is the `@node` function.

Two shapes were possible:

1. Make the domain API itself a node library: every public function is
   decorated with `@node`.
2. Keep plain, importable domain functions and wrap the ones that need
   scheduling policy in a thin node layer.

## Decision

Adopt option 2.

- `src/pyssp_vv/` contains plain functions and data types. Nothing in it
  imports a flow engine.
- `src/pyssp_vv/nodes/` applies `@node` to a small set of work units at
  artifact boundaries.
- Node inputs and outputs are paths and plain data, so they survive a process
  pool.
- `spec`, `evidence`, and `plan` are standard-library only and define the
  interchange contracts. They are the product; wrappers are incidental.

## Rationale

- `@node` is a policy annotation, not a behavioural wrapper: called directly it
  runs inline. The real constraints it imposes are picklability, cancellation,
  and abort containment, not call syntax.
- Keeping nodes in one layer makes the flow engine an optional extra, so the
  core installs on Python 3.10 without it.
- Artifact-boundary nodes are the smallest units that stay reusable across
  projects. Finer granularity produces trivial nodes; coarser granularity
  prevents parallel execution and hides which artifact a step produces.

## Consequences

- Public domain signatures never mention `sequence_extensions`; the flow engine
  cannot leak into consumers who do not want it.
- A node's contract must be catalogued (name, inputs, outputs, status) because
  flows are user code and depend on it.
- Retries and timeouts are declared per node, where they are visible, rather
  than inherited from a global default.
- Engine execution must remain a child-process operation, because a thread
  cannot be preempted and a native abort would destroy the calling pool.
